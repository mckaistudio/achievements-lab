# achievements-lab

A public practice repository for learning GitHub, collaborating on projects, and improving open-source development skills.

## What I am learning

- Working with branches and commits.
- Improving documentation and reviewing pull requests.
- Giving and receiving constructive feedback.
- Collaborating on real, useful open-source changes.

## Your first GitHub contribution

You can practice entirely in your browser:

1. Open this repository and select **Fork** to make your own copy.
2. In your fork, open the branch selector and create a new branch, such as `docs/clarify-example`.
3. Open a Markdown file and select the pencil icon to edit it.
4. Make one meaningful improvement, such as correcting an unclear instruction or adding a verified example.
5. Preview the change, then select **Commit changes**. Use a short message explaining what you changed.
6. Open the **Pull requests** tab and create a pull request against the original repository's `main` branch.
7. Explain why the change helps a beginner, then respond to any review feedback.

## Helpful practice exercises

- Explain the difference between a branch, a commit and a pull request in your own words.
- Add an example of a clear commit message and explain why it is useful.
- Improve an existing instruction after testing it in GitHub.
- Review a real pull request and give specific, respectful feedback.

## Collaboration guidelines

- Keep each contribution focused on one useful improvement.
- Credit actual collaborators; never invent co-authors.
- Do not submit empty changes, duplicate pull requests or requests for artificial stars.
- Never include passwords, API tokens or private project information.
- Be respectful and explain what you tested.

A star is appreciated if you genuinely find this repository useful, but it is never required to contribute.
